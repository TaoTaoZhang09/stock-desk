# 股票交易员 · 中长线模拟盘

这是一个自己看的看盘网页。用 iPhone 的 Safari，或者 Windows 的浏览器打开就行。

不用每次找 AI，也不用装软件。行情**不是实时的**：每个交易日美股收盘之后，自动更新一次。

网页地址：

**https://taotaozhang09.github.io/stock-desk/**

模拟账户从 10 万美元现金开始。页面只记账、只看行情，**不会连接券商，也不会下单**。

仓库是公开的。谁都能打开这个网页。不要把密码、券商账号、银行卡写进任何文件。

---

## 合并之后，你要做的事（只做一次）

用 iPhone 的 Safari。做完一步再做下一步。

### 1. 打开仓库

1. 打开 Safari，登录 GitHub（你自己的账号）。
2. 地址栏输入 `github.com/TaoTaoZhang09/stock-desk`，打开。
3. 如果页面太简、找不到下面说的 Settings：点地址栏左边的「AA」（或「大小」），选 **请求桌面网站**。

### 2. 允许自动任务保存新价格

不设这一步的话，每天的价格更新会失败。

1. 点仓库上方的 **Settings**。
2. 左边菜单点 **Actions**，再点 **General**。
3. 找到 **Workflow permissions**。
4. 选 **Read and write permissions**（读和写）。
5. 点 **Save**。

### 3. 把网页发布出去

1. 还是在 **Settings** 里，左边点 **Pages**。
2. 找到 **Build and deployment**（构建和部署）。
3. **Source**（来源）选 **GitHub Actions**。
4. 选好就会保存。不用再找别的按钮。

### 4. 先手动更新一次

自动更新要等到下一个交易日收盘之后。想马上看到最新页面，就手动跑一次。

1. 打开仓库上方的 **Actions**。
2. 左边点 **更新行情并发布**。
3. 右边点 **Run workflow**。
4. 再点一次绿色的 **Run workflow**。
5. 等它变成绿色的对勾。第一次可能要几分钟。
6. 如果它是红叉：回到上面第 2 步和第 3 步，确认 Pages 的来源是 GitHub Actions，并且权限是读和写。然后再点一次 Run workflow。

### 5. 打开网页，加到主屏幕

1. Safari 打开这个地址：https://taotaozhang09.github.io/stock-desk/
2. 点底部分享按钮（一个方框，旁边有向上的箭头）。
3. 点 **添加到主屏幕**。
4. 以后点那个图标就能看。电脑上把这个地址存进浏览器书签也行。

页面最上角有一行「数据截至 ……（罗马时间）」。那就是这批收盘价对应的罗马时间。

## 价格每天怎么更新

不用你管。

- 周一到周五，美股收盘之后自动跑。
- 罗马时间：冬天大约 **23:30**，夏天大约 **第二天 0:30**。
- 周末不跑。美国节假日（比如感恩节）没有新的收盘价，页面继续显示上一个交易日。
- 某只股票这次没抓到时，页面留着上次的价格，并标「沿用上次」。完全没有旧数据时，显示「暂无数据」，整页不会坏。

想马上再抓一次：按上面「先手动更新一次」的步骤，再点一次 **更新行情并发布**。

只改了模拟账户、没改价格时，另有一个叫 **发布网页** 的任务会自动把网页更新出去。这个不用你点。

## 给帮你改账户的 AI 看

主人平时不用改文件。下面是给 AI 助手的。

看盘本身不需要 AI。只有改模拟账户（买卖记录、建议、闸门、消息）时，才改这一个文件：

`data/portfolio.json`

规则：

- **不要改** `data/market.json`。那是收盘价，自动任务会整份覆盖。
- **不要改**自动任务去写 `portfolio.json`。每天的脚本只会提交 `data/market.json`。
- 改完后提交并推到 `main`。推上去之后，「发布网页」会把网页更新。用 GitHub Actions 自己的身份推送的提交，不会再次触发别的任务；所以改账户请用普通的提交（助手平时的推送就是这种）。
- 价格、涨跌、K 线都从 `data/market.json` 来。建议文字里可以提到价格，但页面上的数字以行情文件为准。
- 网页上的**总权益** = `account.cash` + 每条持仓的 `qty × 最新收盘价`。`equity` 和 `returnPct` 可以不改，页面会自己算。
- `positions`：`sym` 代码，`qty` 股数，`cost` 每股成本（美元），`note` 可以空着。卖光就删掉这一条，或把 `qty` 写成 `0`。
- `gate.open` 为 `false` 表示暂停新的模拟买入。`label` 是短标题，`reason` 是原因。
- `log` 最新的一条放在**最上面**。`act` 用 `BUY`、`SELL`、`HOLD`、`WATCH`、`BLOCK`、`STOP`、`NEWS`、`DATA`。
- `symbols` 里是每只股票的建议、风险、买入条件、事实。没有这只股票的建议时，页面仍显示价格，建议处写「暂无建议」。
- `ladder` 是分批计划，不是成交。`px` 是限价，`size` 是这一批大概多少美元。
- `news[].sym` 用空格分开相关代码，例如 `"NVDA TSLA"`。写上 `大盘` 的消息，也会出现在 SPY、QQQ 这些 ETF 的详情里。
- 文件开头的 `_help` 是给助手看的说明，页面不显示。

模拟买入的例子：确认买入 NVDA 33 股，每股 150 美元，花掉 4950 美元。

1. `account.cash` 改成 `95050`。
2. `positions` 加上 `{ "sym": "NVDA", "qty": 33, "cost": 150, "note": "第 1 批" }`。
3. `log` 最上面加一条，例如 `{ "t": "2026-11-27 22:10", "act": "BUY", "role": "模拟下单", "sym": "NVDA", "val": "33 股", "msg": "模拟买入 NVDA 33 股，价格 150 美元", "detail": "第 1 批。" }`。
4. 提交到 `main`。

这仍然只是账本。没有券商，没有真实委托。

## 想再加一只股票

打开 `config/tickers.json`，在 `tickers` 里照着加**一行**，例如：

```json
{ "sym": "NVDA", "name": "英伟达", "kind": "个股", "group": "core" }
```

`group` 只能是这四个：

| group | 页面上的组 |
| --- | --- |
| `core` | 核心观察（默认展开） |
| `index` | 指数 ETF |
| `mega` | 科技巨头 |
| `other` | 其他 |

加完后，到 Actions 里手动跑一次 **更新行情并发布**，新代码才会有价格。建议文字要写进 `data/portfolio.json` 的 `symbols` 里。不写也能看价格。

## 这些文件是干什么的

| 文件 | 谁来改 | 干什么 |
| --- | --- | --- |
| `index.html`、`css/`、`js/` | 改页面时才动 | 网页本身 |
| `config/tickers.json` | 加股票时改一行 | 看哪些代码、怎么分组 |
| `data/market.json` | 只有自动任务 | 收盘价和 K 线 |
| `data/portfolio.json` | 你或 AI 助手 | 现金、持仓、建议、闸门、记录 |
| `.github/workflows/update-data.yml` | 不用动 | 收盘后抓价格、保存、发布 |
| `.github/workflows/deploy.yml` | 不用动 | 普通提交推进 main 之后发布网页 |

行情来自 Yahoo Finance 的公开接口，不需要密钥。

## 打不开、价格不更新时

- 网页打不开：多半是 Pages 的来源还没选 **GitHub Actions**。回到上面第 3 步。
- 价格好多天没变：打开 Actions，看 **更新行情并发布** 最近一次是不是红叉。可以自己再点 Run workflow。
- 某只股票显示「暂无数据」：等下一次更新，或手动跑一次。其他股票不受影响。
